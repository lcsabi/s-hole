# CL 41: Move Recent Queries below Actions on the dashboard

## Description

The dashboard rendered its full-width panels in the order Recent Queries then
Actions. Recent Queries is a long, always-growing table, so the Actions panel
(reload blocklists, whitelist a domain) sat far down the page and moved as the
query log filled. This CL swaps the two panels. Actions now sits directly under
the two-column Top Blocked / Top Clients row, and Recent Queries goes to the very
bottom.

## Motivation

Actions is the one panel an operator interacts with. It should sit in a stable,
reachable place, not below a table whose height changes with traffic. Recent
Queries is a scrolling read-only log, so the bottom of the page is its natural
home.

## What it does

Reorder two sibling `div.full.panel` blocks in the embedded UI. The bottom-margin
spacer (`style="margin-bottom:32px"`) moves from Actions to Recent Queries so the
last panel keeps the page-end gap. No script change: the JavaScript binds by id
(`#queries`, `#wl-input`, `#action-msg`), which the reorder preserves.
