# CL 55: expose per-source blocklist health

## Description

Carry the per-source blocklist status that `blocklist.Update` computes at each
refresh onto the store, and surface it read-only in `/api/stats`, the dashboard,
and `/metrics`. Implements ROADMAP #17.

## Motivation

The service exposed only the aggregate blocklist size (CL 28). When one
configured source silently returned an empty or truncated list, the total
dropped but the operator could not see which source caused it. The
empty-blocklist alarm (CL 29) catches only the all-empty floor. The per-source
data already existed at refresh time in `Update`; it was logged and then
discarded.

## What it does

- **Data model** (`internal/blocklist/store.go`): new exported `SourceStatus`
  (`URL`, `Count`, `LastRefresh`, `Stale`). `Count` is pre-dedup (what the source
  returned), so the sum across sources is greater than or equal to
  `blocklist_size`. The three states encode as: fresh (`Stale=false`,
  `LastRefresh`=refresh time); stale-cache fallback (`Stale=true`, `LastRefresh`=
  cached snapshot mtime); hard failure (`Stale=true`, zero `LastRefresh`).
- **Carry the data** (`loader.go`): `fetchList` now also returns a `sourceMeta`
  (`stale`, `snapshot`) instead of swallowing the stale-fallback signal and the
  cache mtime. `Update` builds a `[]SourceStatus` as it loops (failed sources
  included) and publishes it via `store.setSources`, even when every source
  failed, so the dashboard shows the outage rather than the last good snapshot.
- **Store storage**: the source list lives in an `atomic.Pointer[[]SourceStatus]`,
  not under the hot-path RWMutex, so the `/api/stats` poll never contends
  `IsBlocked`. `Update` swaps it (single-flight); `Sources()` reads it, nil-safe.
- **API** (`api.go`): a `statsResponse` wraps `stats.Summary` (embedded, so its
  JSON fields stay top-level) and adds `sources`. The wrapper lives in the api
  package, so the stats package keeps no blocklist dependency, the same reason
  `blocklist_size` is set in the handler.
- **Metrics** (`metrics.go`): `shole_blocklist_source_size{url=...}` and
  `shole_blocklist_source_stale{url=...}` gauges, one sample per source. Label
  values are escaped per the Prometheus text format. Cardinality is bounded by
  the configured URL count.
- **Dashboard** (`static/index.html`): a "Blocklist Sources" panel (URL, domain
  count, last refresh, OK/STALE badge), rendered from the existing `/api/stats`
  poll.

## Files changed

- `internal/blocklist/store.go`: `SourceStatus`, `sources` atomic pointer,
  `setSources`, `Sources`.
- `internal/blocklist/loader.go`: `sourceMeta`, `fetchList` signature, `Update`.
- `internal/blocklist/loader_test.go`: per-source status test (healthy + hard
  failure), stale-fallback meta assertions, empty-before-Update test.
- `internal/api/api.go`: `statsResponse`, `handleStats`.
- `internal/api/metrics.go`: per-source gauges; `escapeLabel` helper.
- `internal/api/api_test.go`: `/api/stats` and `/metrics` per-source assertions.
- `internal/api/static/index.html`: Sources panel + `renderSources`.
- Docs: `docs/DESIGN.md` (payload, route, dashboard, metrics list), `README.md`
  (metrics list), `docs/CHANGELOG.md`, `docs/CL.md`, ROADMAP #17 flipped to done.

## Testing

- `make check` clean; `-race` on `blocklist` and `api`.
- `TestUpdate_RecordsPerSourceStatus` covers a healthy source (pre-dedup count,
  not stale, non-zero LastRefresh) and a hard-failing source (zero count, stale,
  zero LastRefresh). `TestFetchList_Non200FallsBackToStaleCache` now asserts the
  stale flag and the cached snapshot mtime.
- `TestStatsAndMetrics_IncludePerSourceHealth` runs a real `Update` against a
  list server and asserts the `sources` array on `/api/stats` and both gauges on
  `/metrics`.
