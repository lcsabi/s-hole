# CL 47: pin the single-flight reload and case-sensitive cache-key invariants

## Description

Close two test gaps found in an invariant audit. Extract the single-flight
blocklist-reload closure from `main()` into a testable `newReloadFn`, and test
it directly (gap 2). Add a cache test that the cache key is case-sensitive, and
document that property at the `key()` enforcement site (gap 3).

## Motivation

An invariant-vs-test audit found two load-bearing invariants that were enforced
but not guarded by a test:

- **Single-flight reload (b/022).** The rule is that the periodic timer, the
  `POST /api/reload` handler, and SIGHUP share one lock, so a second refresh
  cannot start while one is running. The API layer tested its own behavior, and
  `TestReload_ConcurrentCallsCollapse` re-implemented a mutex, but the real
  closure in `main()` that all three callers share was exercised only by the
  manual smoke test. b/022 was exactly this: a mutex living in `api.Server` that
  the timer bypassed. A regression would not have been re-caught.
- **Case-sensitive cache key (b/037).** The cache keys on the query name with
  its wire-format case, on purpose, so a dns-0x20 forwarder's case-randomized
  query is never answered from a differently-cased cache entry. This was
  enforced only by construction (`key()` uses `q.Name` verbatim) with no test
  and no comment saying it was deliberate. A "lowercase the key to raise the hit
  rate" change would have passed the whole suite.

## What it does

- **Gap 2.** `newReloadFn(mu, wg, work) func() bool` is a package-level function
  in `cmd/s-hole`, matching the existing testable-helper pattern (`runTicker`,
  `waitWithDeadline`, `buildMultiLogger`). `main()` now builds `reloadFn` from
  it; behavior is unchanged, including the ordered Unlock-then-Done cleanup.
  `TestNewReloadFn_SingleFlight` asserts the second call returns `false` while a
  refresh is in flight and, critically, that the rejected call never runs the
  work.
- **Gap 3.** `TestCache_KeyIsCaseSensitive` seeds an entry under `Example.COM.`
  and asserts `example.com.` misses while `Example.COM.` hits. The `key()`
  doc comment now records the case-sensitivity as deliberate (b/037, dns-0x20)
  and names the guarding test.

The `main()` extraction also lifted `cmd/s-hole` unit coverage from 31.6 % to
36.0 %, because the reload closure is now reachable from a test.

Refactor plus tests. No product behavior, config, route, or user-visible change,
