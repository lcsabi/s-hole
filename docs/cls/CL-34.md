# CL 34 — Strip the FQDN trailing dot in the dashboard

## Description

The dashboard rendered domain names with the DNS wire-format trailing dot
(`sub.doubleclick.net.`). The handler logs each query as `q.Name`, which is a
fully-qualified name ending in `.`, and that value flows unchanged into the
stats counter, the SQLite query log, and every JSON API payload. The web UI
now strips the trailing dot **at display time** in the two panels that show
domains — Top Blocked Domains (both "Since start" and "All time") and Recent
Queries.

## Motivation

Cosmetic, but visible on every row of the two busiest panels. The trailing
dot is correct FQDN notation but reads as a typo in a UI; every comparable
tool (Pi-hole, AdGuard Home) shows the bare name.

## Design decisions

**Strip in the UI, not at the source.** The trailing dot is stripped in the
static page's render path (`stripDot`), not in the handler before it records
the query. Two reasons:

1. **The stored value stays the true queried name.** The stats counter, the
   `queries` SQLite table, and the `/api/stats`, `/api/queries`, and
   `/api/top-blocked` payloads keep the exact wire-format FQDN. Nothing that
   matches on the name is affected (blocklist matching already normalises the
   dot away in `blocklist.normalize`), and an API consumer still receives the
   real name.
2. **It also fixes history.** A display-time strip cleans up rows already
   written to the query log with a dot. A source-side strip would only affect
   rows recorded after the change, leaving the operator's existing "All time"
   and Recent Queries data dotted until it aged out.

**Scoped to domain columns.** `stripDot` is applied to the Top Blocked
Domains name cell and the Recent Queries domain cell only. Top Clients renders
client IPs (no trailing dot), so it is left untouched rather than passed
through a no-op strip that would wrongly imply the value is an FQDN.

## Files changed

- `internal/api/static/index.html` — added the `stripDot` helper next to
  `esc`/`fmt`; wrapped the domain cell in `renderTopDomains` and the domain
  cell in the Recent Queries render with `stripDot`.
- `docs/CHANGELOG.md` — `Fixed` bullet.
- `docs/CL.md` — index row.
- `docs/cls/CL-34.md` — this file.

No Go code changed: the handler, stats, querylog, and API packages are
untouched, so behaviour, tests, and coverage are unaffected.
